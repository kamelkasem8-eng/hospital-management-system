# Hospital Management System

A robust desktop software application built in Java using NetBeans IDE to streamline medical records, patient admissions, and healthcare administrative workflows.

## Features
- **Patient Management:** Easy registration, profile updating, and medical history tracking.
- **Appointment Scheduling:** Structured system for organizing doctor visits and department operations.
- **Administrative Control:** Secure interface for managing staff records, billing, and operational tasks.
- **Desktop Application Architecture:** Reliable local execution with organized GUI forms.

## Tech Stack
- **Language:** Java
- **IDE:** NetBeans IDE
- **Database:** MySQL / SQLite Integration
- **UI Framework:** Java Swing / AWT
